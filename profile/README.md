# Nebeto Studio

> **Craft, build, impact.** — High-performance web applications, resilient Rust backends, and developer tooling.

At **Nebeto Studio** ([nebeto.xyz](https://nebeto.xyz)), we combine **Software Craftsmanship**, **Security by Design**, and **AI-Augmented Engineering** to ship clean, accessible, and maintainable software with zero technical debt.

---

### Engineering Principles

- **Craftsmanship & Strict Typing** — Strongly typed codebases, automated tests, and explicit OpenAPI 3.1 contracts.
- **Accessibility & Performance** — Native **RGAA 4.1 / WCAG 2.1 AA** compliance (Light & Dark) and strict Core Web Vitals (`CLS 0.00`).
- **Security & Supply Chain** — Zero-Trust architecture, Google Distroless containers, signed commits, SLSA build provenance, and SHA-pinned CI/CD.
- **AI-Augmented Delivery** — Practical AI workflows paired with rigorous human review and specification-driven engineering.

### Core Stack

| Domain | Technologies |
| :--- | :--- |
| **Frontend** | TypeScript, Nuxt 4 (Vue), `@nuxt/ui` v4, Tailwind CSS v4, Playwright |
| **Backend** | Rust (Axum, Tokio, SQLx), PostgreSQL 17, OpenAPI 3.1 (`utoipa`) |
