# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any **Nebeto Studio** repository, please **do not** open a public GitHub issue.

Instead, report it confidentially via one of the following channels:

1. **GitHub Private Vulnerability Reporting** (preferred): use the **Security → Advisories → Report a vulnerability** button on the affected repository.
2. **Email**: send details to **security@nebeto.xyz** (or **contact@nebeto.xyz**).

### What to include

- Affected repository and version / commit SHA
- Step-by-step reproduction instructions or proof of concept
- Potential impact and any suggested mitigation

### Response targets

- **Acknowledgement**: within 48 business hours
- **Triage & severity assessment**: within 5 business hours for critical issues (5 business days otherwise)
- **Remediation & coordinated disclosure**: agreed with the reporter prior to public advisory

Thank you for helping keep Nebeto Studio and its users safe.
